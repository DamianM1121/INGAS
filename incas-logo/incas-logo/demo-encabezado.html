Logo INCAS animado

Fondo transparente: el encabezado de tu web se ve a través del logo. Probá los tres fondos de arriba para comprobarlo.

Cómo se usa (recomendado)

Dos imágenes superpuestas: abajo el fuego en bucle infinito y arriba la intro, que se desvanece sola a los 2,48 s. No requiere JavaScript y el fuego nunca se detiene.

<!-- HTML -->
<div class="logo">
  <img class="logo-fire"  src="incas-logo-fuego-loop.webp" width="640" height="240"
       alt="INCAS — Instalaciones internas, industriales y domiciliarias">
  <img class="logo-intro" src="incas-logo-intro.webp" width="640" height="240"
       alt="" aria-hidden="true">
</div>
/* CSS */
.logo{
  position:relative;
  display:inline-block;
  width:clamp(190px,32vw,290px);   /* ajustá el tamaño acá */
  line-height:0;
}
.logo img{display:block;width:100%;height:auto}

.logo-intro{
  position:absolute;inset:0;pointer-events:none;
  animation:logoIntroOut .3s linear 2.48s forwards;   /* 2,48 s = fin de la intro */
}
@keyframes logoIntroOut{to{opacity:0}}

Alternativa en un solo archivo

Si preferís una sola imagen, usá incas-logo.webp (intro + un ciclo de fuego, en bucle). La aparición de las letras se repite cada 4,48 s, así que se ve más "publicitaria".

<img src="incas-logo.webp" width="640" height="240"
     alt="INCAS — Instalaciones internas, industriales y domiciliarias">

Fondo transparente real

Los WebP conservan el canal alfa, así que se apoya directamente sobre el color o el degradado de tu encabezado. No hay caja blanca.

Borde corregido

El PNG original tenía un halo claro de 1 px alrededor de las letras (artefacto de recorte). Se eliminó: sobre fondo oscuro ya no se ve la línea clara.

Compatible

WebP animado con alfa: Chrome, Edge, Firefox, Safari 14+ (macOS Big Sur / iOS 14) y Android. Es un 30–60 % más liviano que un GIF equivalente.

Ojo con el subtítulo: "Instalaciones internas, industriales y domiciliarias" es gris oscuro (#1B1B1B) y sobre un encabezado oscuro casi no se lee. Si tu encabezado es oscuro, decime y te genero la versión con el subtítulo en blanco (o con las letras en blanco y el fuego a color).
